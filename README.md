The program compresses characters 2 to 1. 
Write your message (now only 32 characters max) to the right TextArea and press the button. 
Your compressed message will appear in the first TextArea.

Characters allowed now: English alphabet, Space, Question mark. (28 in total)

Written on Java with JavaFX and Maven. 
64bit and Java 26 ARE NEEDED!

The last version: 0.0.1
