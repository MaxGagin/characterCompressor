The program compresses characters 2 to 1. 
Write your message (now only 128 characters max) to the left TextArea and press the button. 
Your compressed message will appear in the second TextArea.

Characters allowed now: English alphabet, Space, Question mark, Dot. (29 in total)

Written on Java with JavaFX and Maven. 
64bit and Java 26 ARE NEEDED!

The last version: 0.1

Should work on windows 10.
Please, run this using the bat file if you are using windows 11.
